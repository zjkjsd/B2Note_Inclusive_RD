\section{Validation and Box-Opening Strategy}
\label{sec:validation}

The $B\to D\tau\nu$ signal region is blinded.
Every region in this section is a cross-check: none of them enters the
likelihood of Sec.~\ref{sec:fit}, which uses only the $D$-mass signal region
and the $D$-mass sideband.

\subsection{Known open issues}
\label{sec:validation:issues}

The following technical points need to be resolved:
\begin{itemize}
  \item $E_{\mathrm{cms}}$ and experiment-level data/MC discrepancies in
        several Run~1 and Run~2 experiments, hypothesised to originate from
        background-overlay run mismatches.
  \item A fixed, non-run-dependent $B\bar{B}$ cross section in MC16rd despite
        the $E_{\mathrm{cms}}$ drift across the data-taking period.
  \item Slow-$\pi^{0}$ efficiency corrections for the $D^{*}$ veto region,
        pending an updated MC16rd table.
\end{itemize}
