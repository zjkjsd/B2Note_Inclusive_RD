\section{Variable Lists in the inclusive $R(D)$ analysis}
\label{app:selections}

We list the variables used in the Python analysis scripts.

\subsection{Classifier input variables}
\label{app:selections:mva}

\begin{description}
  \item[Continuum suppression:]
    \texttt{B0\_cosTBTO}, \texttt{B0\_KSFWV3}, \texttt{B0\_KSFWV4},
    \texttt{B0\_KSFWV5}, \texttt{B0\_KSFWV6}, \texttt{B0\_KSFWV7},
    \texttt{B0\_KSFWV9}, \texttt{B0\_KSFWV10}, \texttt{B0\_KSFWV13},
    \texttt{B0\_KSFWV17}
  \item[$D$ vertex and Dalitz Plot:]
    \texttt{D\_A1FflightDistanceSig\_IP}, \texttt{D\_daughterInvM\_1\_2},
    \texttt{D\_daughterInvM\_0\_1}
  \item[$B$ level variables:]
    \texttt{B0\_CMS\_cos\_angle\_0\_1}, \texttt{B0\_D\_l\_DisSig},
    \texttt{B0\_roeMbc\_my\_mask}, \texttt{B0\_roeDeltae\_my\_mask}
  \item[Spectators (carried, not trained on)]
    \texttt{\_\_weight\_\_}, \texttt{D\_CMS\_p}, \texttt{ell\_CMS\_p}
\end{description}

The two spectator momenta are the components of the second fit observable,
$\pdl$ (Sec.~\ref{sec:recon:b}). These variables are not used in the BDT classifier.

\subsection{Combinatorial-enriched region}
\label{app:selections:cuts}

The selections \texttt{offline\_cut} (Eq.~\eqref{eq:offline-cut}),
\texttt{lgb\_tight} (Eq.~\eqref{eq:lgb-tight}), the $D^{*}$ veto
(Sec.~\ref{sec:recon:dstveto}) and the generic-$B\bar{B}$ tuning region
(Eq.~\eqref{eq:bbbar-region}) are defined in the main text.
The remaining BDT selection is
\begin{description}
  \item[\texttt{lgb\_comb} (combinatorial-enriched region)]
    \texttt{fakeD\_prob < 0.15}, \texttt{continuum\_prob < 0.5},
    \texttt{combinatorial\_prob > 0.5}
\end{description}
